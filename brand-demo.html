Erkläre mir in 3 Sätzen was ein MCP-Server ist.
Ein MCP-Server erweitert die Fähigkeiten eines KI-Agenten, indem er ihm Zugriff auf externe Tools und Datenquellen gibt. Er fungiert als Brücke zwischen dem Agenten und der realen Welt — z.B. Dateisystem, APIs oder Datenbanken. Dabei definiert der Server genau, welche Aktionen erlaubt sind und welche nicht.

21 · Accordion / Collapsible

Ein KI-Agent ist ein System, das autonom Aufgaben ausführen kann. Im Gegensatz zu einem einfachen Chatbot kann ein Agent eigenständig planen, Tools verwenden und mehrstufige Prozesse durchlaufen — zum Beispiel Dateien lesen, Code schreiben oder APIs aufrufen.
Nein. Die Lernreise ist so gestaltet, dass auch Nicht-Techniker agentische Tools einsetzen können. Für den Anwenden-Pfad reicht es, wenn Sie einen Browser bedienen können. Fortgeschrittene Module in Phase 4 bieten optionale Vertiefung für technisch Interessierte.
Die Lernreise hat 4 Phasen. Sie arbeiten in Ihrem eigenen Tempo — es gibt keinen festen Zeitrahmen. Alle Module bleiben dauerhaft zugänglich, sobald sie freigeschaltet sind.
Ein eigener API-Key ist optional — die Sandbox funktioniert auch mit dem Server-Key. Falls Sie einen eigenen Key nutzen möchten: Bei OpenRouter zahlen Sie nur pro Nutzung. Für die Lernreise fallen typischerweise Kosten unter 5 € an.
